# Apollo Project Roadmap

## Q3 — Analytics dashboard
The analytics dashboard ships in Q3. It visualizes customer revenue trends in real
time, supports CSV export, and lets account managers filter by region and segment.
The dashboard is built on the reporting API and refreshes every five minutes.

## Q4 — Reporting API and performance
Q4 focuses on the public reporting API (rate-limited, OAuth2-protected) and on
platform performance: target p95 query latency under 300ms and a 30% reduction in
ingest cost through batched embedding.

## Owners
The analytics dashboard is owned by the Data team (lead: Ada Lovelace). The reporting
API is owned by the Platform team (lead: Grace Hopper).
